NexusKit v0.4.0 将四个 beta 中迭代的技能体系发布为正式版。技能主体切换为 addyosmani/agent-skills 的简体中文版，25 个技能完成逐技能审阅与全面中文精修；维护者确认当前对 agent 的行为约束已经稳定。本版相对 v0.3.1 是技能主体、命令层与项目接入方式的整体切换。

## 技能主体与中文精修

- **25 个技能**：平铺在 `skills/`，保留上游技能名、目录名与英文 H1；frontmatter `description` 保留上游英文原文，正文使用简体中文。技能按需调用，不强制走完整流水线。
- **全面中文精修**：六个批次依次校对 Meta、Define、Plan、Build、Verify、Review、Ship，以及共享参考、子智能体和命令。精修统一术语、消除直译腔，保留原句的否定词、强制级别、限定条件与数值边界。
- **术语收口**：原 `CONCEPTS.md` 与 `context.md` 合并为 `docs/glossary.md`，记录现行译法、NexusKit 自有概念与已退役的 v0.3.x 术语。
- **上游修正**：以 v0.6.13 为基底，回填 v0.6.14 / v0.6.15 及后续 `301b02b`（PR #736）的可翻译修正。具体来源与本地改动见 `docs/skill-sources.md`。

## 命令、子智能体与项目接入

- **10 个 `nk-` 命令**：9 个上游命令移除 `agent-skills:` 前缀并改为 `nk-` 前缀；新增 `/nk-init`。全部配置 `disable-model-invocation: true`，仅由用户显式调用。
- **`/nk-init`**：逐项确认规则文件、idea / ADR / spec / task 落点、外置工具、子智能体模型与覆盖层级，再写入项目约定。选用外置 tracker 时，在项目内生成自包含的 `docs/agents/issue-tracker.md`。
- **5 个子智能体**：保留 4 个上游专业视角并补充模型约定；新增只读的 `doubt-challenger`，用于对抗式证伪。派发时按项目约定显式传 `model`。

## 行为约束与质量门禁

- **审查发现核实**：`code-review-and-quality` 回填 PR #736，要求报告发现前对照可达调用方、守卫条件与测试核实，区分原有缺陷与新引入回归，并明确零发现也是有效结果。
- **安全扫描**：暂存密钥检查只列命中文件名，不回显命中的值；ownership 检查前先返回 404；`session cookies` 纳入安全技能触发范围。
- **质量标准可执行**：`quality-gate.mjs` 让 Semgrep 与 axe 的 high / critical 发现真正以非零状态退出，并要求用故意违规和干净对照验证门禁。
- **任务跟踪与建图**：仓库任务跟踪切换到 beads。issue graph 最终采用单层父子、`blocks` 与 `provenance` 边、checkpoint 收口和一轮审查的最小约定；beta.3 发布说明中的 root epic / workstream 等旧规则已作废，以 beta.4 及当前 `references/issue-graph.md` 为准。

## 旧技能与客户端范围

- 旧版 23 个 `nk-*` 技能封存于 `archive/v0.3.x-nk-skills` 分支。本版不恢复旧技能的 legacy 副本；尚未裁定的 10 项不在 v0.4.0 提回，挂起到后续版本按真实项目需求重新裁定。
- Claude Code 插件是主体分发形态，也可通过 skills CLI 只安装技能。Codex 安装方式因 vendored 技能超出读取上限而废止，v0.4.0 不提供 Kimi 插件。
- 仓库清理停用的 Codex / Cursor 配置和旧 Kimi 清单，新增 Antigravity `SessionStart` hook，自动注入 `bd prime` 的 beads 工作上下文。
- **仓库维护方式**：移除 `docs/plans/` 仓库级计划文档，后续任务与进度由 beads 承接；历史计划与审阅记录从 Git 历史查找，发布证据保留在 `docs/releases/`、Git 历史与 PR 记录。

## 升级与回退

按 README 更新或重装插件，确认客户端加载的是 `0.4.0` 快照；仓库改动不会自动更新已安装版本。旧项目由 `/nk-init` 写入的项目约定仍保留在项目内，不会因插件升级被自动重写。

如需暂时回退，可重新安装 `v0.3.1` 或 `v0.4.0-beta.4` 的历史快照。已发布 tag 不重打；正式版后发现的问题通过后续版本修正。

## 验证与边界

- 仓库机械检查六项通过：链接、技能引用、入口大小、分发、artifact 路径与 frontmatter；检查器单测 34 项通过。
- 三个版本清单统一为 `0.4.0`，正式版发布说明为 `docs/releases/v0.4.0.md`；发布前另以 `v0.4.0` 模拟 tag 校验。
- Antigravity hook 的配置与输出已对照官方文档，并从实际运行目录完成 smoke test，确认能注入 `bd prime` 上下文。
- 机械检查和 hook smoke test 不等于全部技能的真实客户端端到端验收；本版转正是基于维护者对当前行为约束稳定性的确认。
