# NexusKit v0.2.0

技能体系联合重构的正式版。维护者已完成 U3 沙盒测试，确认基本使用和触发流程通过验收，本轮重构的基本任务完成。

## 本版交付

- 交付重构后的 18 个 nk-* 技能与共享约定：需求与 Plan 交接、单元实施、审查与提交、分支收尾、知识沉淀和手动工具的职责已统一。完整变化见 [beta 发布说明](v0.2.0-beta.1.md)。
- 相比 `v0.2.0-beta.1`，技能执行内容保持不变；本版纳入 U3 验收记录，将 Codex/Kimi 插件版本统一为 `0.2.0`，同步正式版状态与后续路线。
- U3 在独立 notes CLI 沙盒中验证实际技能读取、自然请求触发与手动入口，以及需求规划、调试、实施、审查、提交和分支收尾；合并后 10 项 CLI 测试通过。详细场景、提交和覆盖边界见 [验证记录](../reviews/feat-skill-deep-audit.md)。本次发布复用该证据，不冒充重新执行沙盒测试。
- 发布检查包括五项仓库检查、35 项检查器回归测试、wizard Bash 模板语法，以及版本 tag 与清单、发布说明的一致性。

## 已知问题与后续路线

- 剩余问题主要为技能内容与方法论改进，包括 [#42：小改动审查编队与返回契约](https://github.com/steven123397/nexuskit-skills/issues/42)，不阻断本次正式版。
- 下一步由维护者在 paper30min 实际开发中使用 `v0.2.0`，发现的问题在后续 `v0.2.x` 中逐步修复；本次发布不包含 paper30min 安装或实装验收。
- `v0.3.0` 目前仅有初步概念构想，暂不启动新一轮大迭代。

升级请按 [README](../../README.md) 使用对应客户端的整套安装方式。基本流程验收不扩大为全部技能、客户端和场景逐项实测的结论；具体实测范围以验证记录为准。
