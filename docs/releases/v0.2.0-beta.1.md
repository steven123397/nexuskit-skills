本版是技能体系联合重构后的预发布版，从 main 发布。用途是固定沙盒实际测试的版本基线；不代表客户端加载、选路与完整执行流程已经通过验收。

## 主要变化

- 重构 18 个技能：主流程持有执行顺序，完整阶段材料就近读取，条件分支按需加载；共享方法单源维护，短底线副本受机械检查约束。
- 统一需求与实施交接：brainstorm 的需求阶段 Plan 由 plan 就地补全；wayfinder 保留独立决策地图路线，经 plan 形成同规格实施 Plan；work 一次处理一个确认单元。
- 明确质量与提交职责：work/debug 调度常规 review，包含精简分析和独立复核；修复后核对适用证据，由 commit 同次维护 current 并提交。handoff 仅用于显式保存未完成现场。
- close 负责分支生命周期，使用轻量 pre-merge 检查累计成果；知识承接后清理已消费产物，保留活跃消费者需要的材料。收尾与合并、发布分别授权。
- compound 统一知识沉淀与审计，协作复盘按明确请求进入；项目指导提供 solutions 的定向检索入口。修正术语初建被共享约定误导向 refresh 的残留。
- 明确 grill、wayfinder、wizard、wait-what 等手动工具边界；wait-what 由 Agent 重新解释。to-issue 支持当前会话及已授权的嵌入调用；ask-ljq 按最新工具箱重写。
- 全部技能及 conventions 的 description 统一英文；正文保留中文。这是维护者选择，不是“英文触发效果更优”的实验结论。
