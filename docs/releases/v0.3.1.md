NexusKit v0.3.1 是 v0.3.0 系列的迭代版本，移除 Orca 执行底座接入。共 23 个技能，按需组合；`nk-odyssey` 保持“测试中”，继续随套件分发。

## 相对 v0.3.0 的调整

- 移除 Orca 接入（技能数 24 → 23）：删除 `nk-orca-guide`；`nk-init` 不再探测或写入 Orca 配置；`nk-odyssey` 删除执行底座分流；`nk-review`、`nk-spec-close` 去掉 Orca 交叉引用。推荐搭配只剩 Linear。
- 实施与合并子代理统一回归原生派发：工作树按仓库惯例建于同级 `<项目名>-worktrees/<用途>`，宿主管理的工作树走宿主入口清理，不依赖特定执行底座软件。
- CONCEPTS 移除「执行底座」词条，skill-sources 删除 STE-33 对应来源记录。v0.3.0 及更早的发布记录保持原貌，Orca 曾随套件分发的事实由各版本记录承载。

## 验证与适用范围

- python tests/run_checks.py 五项通过（链接、引用、大小、分发、frontmatter），技能清单与数量声明与磁盘一致。
- 仓库机械检查不证明客户端执行效果；已安装旧快照的客户端需重装才会生效，使用过 `nk-init` 写入 Orca 声明的项目可删除指令文件中的声明与 `.gitignore` 的 `/.orca/` 条目。

升级请按 README 重装或更新所用客户端的整套技能，并确认加载的是新版本快照。具体来源与改写归属见 docs/skill-sources.md 和 NOTICE。
