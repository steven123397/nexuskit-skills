本版是整套技能按简洁工作流重写后的预发布版，从 main 发布。用途是固定真实客户端安装验收的版本基线；不代表各客户端的加载与执行流程已经通过验收。

## 主要变化

- 全套重写为 23 个 `nk-*` 技能，按 engineering / productivity 分组；退役 brainstorm、ideate、plan、work、handoff、compound、close、simplify 八个旧入口与集中 conventions 共享层。
- 主线：grill/wayfinder → to-spec/to-tickets → implement/odyssey → review/spec-close → pr；单个无 spec 问题可直接走实施/review/PR。spec 整体验收通过即关 Linear 票，不等分支合并；审查结论按范围复用。
- 新增 nk-init（项目接入）、nk-pr（分支交付收尾）、nk-spec-close（整体验收）、nk-research 与 nk-prototype（探索配套）、nk-domain-modeling（术语与 ADR）、nk-tdd 与 nk-codecraft（model-invoked 纪律参考）、nk-prose（面向人的写作）、nk-retro（复盘入口）。
- nk-review 改为需求符合性、实现正确性、简洁性与可维护性三轴独立审查，返回自然语言发现；处理旧编队成本与零发现 JSON 契约问题（Related: #42）。
- 知识与交接分工：Linear 管内部 spec/ticket，GitHub Issues 管外部反馈，OpenViking 管背景与经验，Git/PR 管交付事实；取消 current.md 状态文档与 solutions 仓库流程，旧材料按 STE-13 迁移。
