NexusKit v0.4.0-beta.2 是 v0.4.0 的第二个预发布版，在 beta.1 基线上回填上游 addyosmani/agent-skills 0.6.14 与 0.6.15 的安全、质量门禁与命令调用权限修正，并将任务跟踪切换为 beads。用途仍是固定真实客户端安装验收的版本基线；不代表客户端加载与执行流程已经通过验收。

## 主要变化

- **安全扫描**：`security-and-hardening` 的暂存密钥检查改为 `git diff --cached -i -G'…' --name-only`，只输出命中文件的文件名，不再把命中的值打印到终端或 agent transcript，git 失败时也不会误判为干净；ownership 检查前先返回 404；description 补 `session cookies`。同一检查同步到 `references/security-checklist.md`。
- **质量门禁**：`constraint-driven-development` 新增 `scripts/quality-gate.mjs`，Semgrep 与 axe 的 high/critical 发现会让命令以非零退出，而不是报告生成完就算通过；同步 `gitleaks dir` 调用、`check:security` / `check:a11y` 脚本映射，并要求用故意违规与干净对照验证每条门禁。
- **命令调用权限**：9 个 `nk-*` 命令补充 `disable-model-invocation: true`，与上游一致仅允许用户手动调用，避免模型自行启动 `/nk-ship`、`/nk-build` 等命令。
- **任务跟踪**：切换到 beads（`.beads/`），新增 ADR 0003 记录决策；`CLAUDE.md` 改为指向 `AGENTS.md` 的指针，清理旧审计文档与 tracker 表述。
- **版本**：插件清单与两个市场清单统一为 `0.4.0-beta.2`。

## 分发与维护检查

- 检查覆盖链接、引用、入口大小、分发、frontmatter 与 artifact 路径；CI 在 PR、main 与版本 tag 上覆盖 Windows/Linux，版本 tag 另校验版本号与 release notes。
- 技能数量、命令数量与子智能体数量不变：25 个技能、10 个命令、5 个 agent。

## 验证与限制

- 仓库机械检查六项通过；检查器单测通过。
- `quality-gate.mjs` 以干净报告、blocking 报告、不可解析报告三种输入验证退出码 0 / 1 / 2。
- 未做真实客户端的安装验收；`disable-model-invocation` 的实际行为需在 Claude Code 中确认，机械检查不证明客户端执行效果。
