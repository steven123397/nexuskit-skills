本版是 v0.3.0 系列的第二个预发布版，从 main 发布。内容为 STE-33 的 Orca 执行底座接入第一批：Orca 可选承载落工作树的实施与派发，方法论仍归 nk 技能。用途仍是固定真实客户端安装验收的版本基线；不代表各客户端的加载与执行流程已经通过验收。

## 主要变化

- 新增 nk-orca-guide（技能总数 23 → 24）：Orca 执行底座操作指南——CLI 解析（含 WSL 环境变量注入、Linux 非托管会话用 orca-ide 防命中 GNOME 屏幕阅读器、失败不回退换构建）、建工作树并派发 agent、发送/等待/读屏差异、完工确认（卡片 / Linear / 物证兜底）与清理，附 agent 差异速查与已知坑。
- nk-init 增加 Orca 接入：探测（托管终端环境变量、PATH 上 CLI、外挂技能 orca-cli）→ 确认（本项目是否用 Orca 管理工作树与派发）→ 写入（`.gitignore` 追加 `/.orca/`、指令文件一两句声明）。
- nk-odyssey 新增执行底座分流：走 Orca 时工作树与实施、合并子代理改用 Orca 方式，不落工作树的探索与审查子代理始终原生；nk-review 明确 reviewer 只读不占工作树、不走 Orca。
- 分流判据与术语收入 CONCEPTS「执行底座」词条；spec-close 兜底清理与 init 收尾告知补 Orca 交叉引用；README 目录树补齐 codecraft/tdd。
- 三轴独立审查后修正指南事实：agent 句柄按 `agentTerminalHandle` → `startupTerminal.handle` → `terminal list` 回退、`--current` 按当前目录解析、完工确认与探测命令面按本机 orca 1.4.223 逐一核对。
- release notes 移除大标题，避免与 GitHub 发布页标题重复。
