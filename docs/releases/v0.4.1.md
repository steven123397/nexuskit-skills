NexusKit v0.4.1 同步 addyosmani/agent-skills 0.6.16–0.6.17 的可 vendor 内容，引入无障碍审计套件与 Spec 演进工作流，并修复本轮审查发现的 Windows 脚本兼容问题和外部 tracker 溯源门禁。技能、命令与子智能体现为 26 / 11 / 6。

## 上游同步

- **Accessibility Engineering**：新增 `accessibility-engineering` 技能、`accessibility-auditor` 子智能体与 `/nk-a11y` 命令，覆盖 WCAG 2.2 AA、axe-core / pa11y 报告和人工审计流程。
- **Spec 演进**：支持 V1 范围界定、延后项与根级 delta spec；`/nk-spec` 分流新建与后续变更，`/nk-build` 优先选择未实现的 delta spec，并校验计划来源。
- **文档与安全**：加入文档漂移判断，OWASP Top 10 更新至 2025 版编号，补充会话密钥启动校验、Vercel 回滚认证及多项触发词和门禁修正。
- 同步点为上游 `8c99fa3`（0.6.17）；逐技能来源、未 vendor 范围与本地适配见 `docs/skill-sources.md`。

## 修复与项目约定

- **Windows 无障碍脚本**：Node 合并与文本输出阶段改用 argv 传路径，避免 Git Bash 使用 POSIX 临时目录时解析到错误的盘符路径。
- **外部 tracker 溯源**：使用 beads 等 tracker 时，各 phase 工作单元记录 `Source spec:`；完整计划与跨 phase 有序索引放在第一个 phase 工作单元。`/nk-build` 复用前校验，缺失或不匹配则停止询问。计划与任务索引保留在 tracker，不建立 Markdown 镜像。
- **Phase 标签**：统一使用 `phase1` / `phaseN`，子票携带所属 phase 标签以便筛选；跨 phase 横切工作不打 phase 标签。

## 升级与回退

按 README 刷新 marketplace 并更新插件，确认客户端加载的是 `0.4.1` 快照。更新后需要重启 Claude Code 会话；当前已启动的会话不会因刷新仓库或 marketplace 自动切换版本。

如需回退，可重新安装 `v0.4.0` 的历史快照。已发布 tag 不重打，后续问题通过新版本修正。
