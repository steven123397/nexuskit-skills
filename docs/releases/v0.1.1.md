## 新增与变更

- **Issue 全生命周期规范**（`skills/conventions/issue-writing.md` 升级为唯一持有者）：
  - 标签最小化：只用 GitHub 默认标签表达类型，不设状态标签（`wayfinder:*` 为唯一例外）；
  - 容器中立认领：`nk-brainstorm` / `nk-plan` / `nk-work` 三条路径同一机制（assignee + 溯源评论），认领后不做须退回；
  - 三个关闭时机：`nk-work` 单元交付、PR `Fixes #N`、`nk-close` 兜底扫描（附机械核对方法）；
  - 验收标准改为可选的纯文本"完成定义"，不用 checkbox。
- **收尾锚定分支生命周期**（`nk-close` 两种触发 + 发布日扫尾）：分支合并前全量收尾；单分支项目保留按 plan 收尾的降级路径；发布与收尾解耦——发布是打 tag + release notes 的纯事件，不做大扫除。
- **新增 `/nk-grill`**：手动召唤的盘问微技能（设计树 + 前沿轮次 + 每问带推荐答案，事实查证归 Agent）；豁免"单轮最多 3 问"上限（用户主动召唤场景，全局规则不动）。
- **PR 描述规范**（`skills/nk-close/references/pr-description.md`）：蒸馏自 CE 208 行原文至约 50 行——写 diff 看不出来的东西、长度随决策成本伸缩、`Fixes #N` / `Related: #N` 语义、项目约定优先。
- **Kimi 插件清单迁至 `.kimi-plugin/plugin.json`**：目录形态与 `.codex-plugin/` 对齐。
- **新增 `CONCEPTS.md` 术语表**并挂入 `AGENTS.md` 知识入口。
- `nk-close` 首次实战后的 5 处摩擦修复（兜底扫描机械方法、决策点前置、发布日扫尾去重等）。
