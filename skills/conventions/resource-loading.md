# 按需读取与复用

<!-- fragment: planning-reading -->
只加载本次路线和选中角色所需材料。上下文中完整、适用且未变的原文直接复用，缺失或变化才补读；阶段切换不触发重读。必需材料缺失且无降级路径时，停在其管辖动作之前。
<!-- /fragment -->

使用技能阶段规则或共享方法前，必须掌握本次适用的原文；只加载当前选中路线和角色，不预读互不相关的分支。

当前上下文已有完整、适用且未变更的原文时直接复用。只剩摘要、内容缺失、文件已改或适用范围改变时，补读受影响的段落及必要上下文；不能凭模糊记忆执行。进入新阶段或回到旧阶段本身不构成重读理由。

技能中“先读”“必读”“再读”描述的是规则的使用时机，不要求重复加载已掌握的原文。需要重新核对的是当前产物或现场时，核对产物与现场，不重新读规则代替核对。

必需文件不可用且没有明确降级路径时，在其管辖的动作之前停下并报告缺失，不自行编造规则。条件分支未命中则无需加载，也无需检查该分支文件。
