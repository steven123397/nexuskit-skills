# Grill（盘问）

> **路径解析说明：** 本文件中引用的参考文件（如 `../conventions/`）均相对于本技能所在目录解析，不在目标代码仓库中查找。

用户主动召唤盘问时使用。围绕用户给出的计划、决策或想法持续追问，直到达成共识。把主题映射为**设计树**：每个决策分叉出挂在它下面的子决策。

## 前沿轮次

**前沿**是前提已全部敲定的决策集合——现在就能问、不需要猜任何未听到答案的问题。一轮问完整个前沿：每问编号、附推荐答案，然后等用户答完再开下一轮。

一轮的格式：

```
**Q1 · <问题标题>**：<问题正文，可多段，可含多个候选>

推荐：<你的推荐答案与一句理由>

---

**Q2 · <问题标题>**：<问题正文>

推荐：<你的推荐答案与一句理由>
```

每轮回答会重塑设计树：敲定的决策把前沿向外推，解锁依赖它们的问题。重算前沿再开下一轮。答案取决于本轮未定问题的问题，属于后面的轮次，不进本轮。

**本技能豁免"单轮最多 3 个问题"上限。** [`../conventions/decision-autonomy.md`](../conventions/decision-autonomy.md) 的批量提问上限针对 Agent 主动打断的场景（用户在忙别的，被打断成本高）；本技能由用户主动召唤，认知带宽本就预备给这场对话，一轮问完整个前沿正是目标体验。问题数超过客户端提问工具上限时，退回对话内的编号列表呈现。

## 事实查证归 Agent

前沿问题需要环境事实（文件系统、工具、外部资料）时自己去查，支持子代理就派发子代理；不问用户任何自己查得到的东西。不阻塞：查证未完成视为前提未敲定，只有依赖它的下游问题等结果，其余前沿照问。子代理按 [`../conventions/subagent-results.md`](../conventions/subagent-results.md) 回传核实结论、来源与未决事实，不回传完整探索过程。**决策是用户的**：每个决策都摆给用户，等回答。

## 完成标志

前沿清空——设计树每个分支都走到，没有静默假设残留——且用户确认已达成共识后，才可行动。结论如需固化为需求或计划，转向 `nk-brainstorm` / `nk-plan`；本技能不强制产生文档产物。

**边界**：本技能是用户主动发起的盘问；Agent 自己拿不准时的提问仍按 `decision-autonomy.md` 执行（选项驱动、带推荐、单轮最多 3 个）。
